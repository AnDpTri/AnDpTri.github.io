# Vector artwork reconstruction

- `edge.svg`: viewBox `0 0 1920 1080`. Dark title silhouettes fit source frame 0040. Lower row contours extracted and simplified from source; upper row manually reconstructed as angular polygons where browser/site overlays obstruct source. The source deliberately crops the title at the viewport edges; this asset represents that composition, not a complete uncropped alphabet. Fill can be recolored using Canvas source-in or SVG replacement. No fonts or embedded raster.
- `logo.svg`: viewBox `0 0 960 240`. Source frames 0079–0100 aligned using template correlation, then median combined to suppress scanlines/static. Shape boundaries converted to simplified vector paths. Subtitle negative-space lettering is transparent. Script yellow over yellow/orange/red gradient stripe base. Template origin on frame0085 is (575,350), size960x240, source1920x1080. Visible ink roughly x8..947,y11..232; retain this viewBox for trajectory measurements.
- Exact sample positions: frame79 (487,396), frame85 (575,350), frame100 (796,234), all template top-left in source pixels.
- Fidelity limits: subpixel scan texture and bloom belong to the renderer, not paths. Upper title edges hidden by recording overlays are reconstructed estimates. Very fine logo strokes slightly simplified to remove compression noise; not claimed as original studio vector source.
- QA: rendered both actual SVG files in headless installed Chrome using Playwright. Inspected `work/letter-svg-browser.png`; no missing glyphs or malformed holes. Mask development previews also inspected.
